# Wordly: обновление «Карточки со свайпами»

Это небольшое обновление для уже установленной финальной версии Wordly (этап 2, со словарём, грамматикой и медиаданными). Это не полный автономный дистрибутив: картинки, аудио и остальные файлы остаются из вашей текущей версии.

## Как обновить GitHub Pages

1. В текущем Wordly откройте настройки и экспортируйте прогресс для резервной копии.
2. Распакуйте ZIP в отдельную папку.
3. Скопируйте `index.html`, `sw.js` и папку `assets` из обновления в локальную папку репозитория `friendly-octo-fiesta`.
4. Подтвердите замену одноимённых файлов. **Папку assets нужно объединить с существующей, а не удалить старую.** В ней должны остаться все картинки, записи и модули.
5. В GitHub Desktop введите Summary: `Add swipe cards`, нажмите **Commit to main**, затем **Push origin**.
6. Дождитесь успешного завершения публикации в GitHub → Actions.
7. Откройте https://qentower.github.io/friendly-octo-fiesta/?update=swipe-v3. Если видна старая версия, обновите страницу через Ctrl+Shift+R. В Telegram закройте и заново откройте мини-приложение после обновления сайта.

В ZIP находятся четыре файла приложения: `index.html`, `sw.js`, `assets/app.js`, `assets/swipe.css`. Остальное — эта инструкция. Заново загружать медиатеку не нужно.

## Как заниматься

- **Слова → Наборы**: выберите набор или нажмите «Учить». Сразу откроются карточки.
- Вспомните значение и нажмите **«Показать перевод»**.
- **Вправо — знаю**, **влево — пока не знаю**. Кнопки внизу делают то же самое. До открытия ответа оценка недоступна.
- «Знаю» соответствует «Хорошо» в планировщике Wordly; «Пока не знаю» — «Снова». Повторения используют ваши лимиты и интервалы. На новых карточках короткие интервалы нормальны: успешные повторения постепенно увеличивают их.
- «Отменить» возвращает последнюю оценку и прежнее расписание. После занятий в другом режиме устаревшая отмена может стать недоступной, чтобы не затереть новый прогресс.
- При коротком перерыве можно закрыть экран: выбранный набор, очередь и место остановки сохраняются. Откройте **Слова → Сегодня → Продолжить карточки**. На главной также есть «Продолжить слова».
- Сохранённая незаконченная свободная практика также возобновляется с этого блока.
- **Свободная практика** позволяет заниматься без ожидания и не меняет интервалы основного расписания.
- **Обзор → Слова и режимы** сохраняет доступ к списку слов и прежним тренировкам. Классический экран доступен через «Другие способы практики».
- Переключатель **EN → RU / RU → EN** меняет направление. Картинки, записи, примеры и перевод примера по подсказке сохранены.

## Что важно знать

- Это собственная реализация свайпов поверх планировщика Wordly, а не копия алгоритма DuoCards или FSRS из Anki.
- Напоминание сейчас внутри приложения. Уведомления Telegram по расписанию не подключены.
- Прогресс сохраняется локально в браузере/Telegram на текущем устройстве. Облачной синхронизации нет. Не очищайте данные сайта; регулярно делайте экспорт. Браузер и Telegram могут хранить разные копии прогресса.
- Обновление не меняет материалы уроков, чтения, грамматики, времён и справочника.
