# Wordly · личная версия, этап 2

## Что внутри

- 6082 словарные карточки, включая 120 выражений; 24 тематических набора и коллекции из ваших Anki-файлов.
- 64 самостоятельных урока Wordly и 50 текстов для чтения (A1–C1).
- 1632 импортированных грамматических задания: Exercises — 809, Activities — 623, Advanced Activities — 200. Это доступные разделы исходных колод, а не полные учебники. Уровни CEFR искусственно не присваивались.
- Грамматика: ввод в пропуски, один/несколько правильных вариантов, несколько пропусков, варианты сокращений из ключа, решение после ответа, продолжение тренировки и отдельное повторение ошибок через 1/3/7 дней.
- Аудио у 5471 словарной карточки и 838 грамматических заданий. Слово, определение, примеры, диалоги — в зависимости от исходной карточки. Записи, относящиеся к импортированным карточкам, сохранены отдельными файлами. Встроенные словарные карточки без записи предлагают явно обозначенную системную озвучку, если она доступна на устройстве.
- Аудирование слов — практика без изменения словарных интервалов. В настройках доступны автопроигрывание слова и скорость. На некоторых устройствах первый звук требует нажатия.
- Видео: готовых видеоуроков в источниках НЕТ. Личная медиатека открывает локальный файл либо прямую HTTPS-ссылку на MP4/WebM/аудио. Это не интеграция с YouTube. Локальный файл выбирается заново после закрытия; ссылки и позиция просмотра сохраняются.
- Планировщик Wordly — собственный SM-2-подобный, НЕ FSRS и не точная копия Anki. История Anki не импортируется.

## 1. Запуск на компьютере

Распакуйте **весь архив**. Откройте `index.html`, не перемещая его отдельно от `assets`.
Все вложенные аудио и картинки доступны без интернета. Внешняя видеоссылка и библиотека Telegram требуют интернета; отсутствие Telegram SDK не должно мешать локальному курсу.
Если браузер ограничивает локальные файлы, запустите из папки приложения:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000` в своём браузере. Это локальный сервер на вашем устройстве, не публикация в интернете.

На телефоне удобнее HTTPS-сайт, чем HTML из файлового менеджера. Поддержка локальных файлов различается между ОС и браузерами.

## 2. Перенос текущего прогресса

1. В прежней версии: Настройки → Экспорт прогресса.
2. В новой: Настройки → Импорт прогресса.
3. Убедитесь, что слова и уроки перенеслись. Исходные ID старых карточек и курс сохранены.

Браузер, адрес сайта и Telegram WebView могут иметь разные локальные хранилища. Общего облачного аккаунта и автоматической межустройственной синхронизации здесь нет. Telegram CloudStorage для всего прогресса не используется.
Регулярно экспортируйте JSON. Не коммитьте его в GitHub. Импорт заменяет состояние после подтверждения и сохраняет локальную копию до замены.

## 3. Размещение и права на материалы — сначала прочитайте

Материалы импортированы из предоставленных вами колод, в том числе учебников и коммерческих иллюстраций/аудио. Лицензия Anki не распространяется автоматически на содержимое чужих колод. Права на публичное распространение этих материалов не проверены.

**Не загружайте этот архив в открытый репозиторий и не публикуйте материалы на общедоступном сайте, пока не проверите права.** Приватный GitHub-репозиторий сам по себе не делает GitHub Pages приватным. Кнопка Telegram тоже не ограничивает доступ к веб-адресу; Telegram initData в этой статической версии не является проверенной сервером авторизацией.

Для личной закрытой веб-версии потребуется хостинг с реальной авторизацией и защитой всех assets на стороне сервера/прокси. Это НЕ реализовано в статическом архиве. Пока можно пользоваться локально.

### GitHub Pages — только после решения вопроса прав

Проект статический, сборка не нужна. Репозиторий должен содержать `index.html`, `assets`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `.nojekyll` в корне. Архив ZIP в репозитории вместо распакованных файлов не запустит сайт.
В `assets` много файлов: удобнее Git, а не веб-загрузчик GitHub.

```bash
cd /путь/к/распакованной/папке

git init
git add .
git commit -m "Add personal Wordly web app"
git branch -M main
git remote add origin https://github.com/YOUR-LOGIN/YOUR-REPO.git
git push -u origin main
```

Используйте собственные LOGIN и REPO; это примеры, не адрес готового сайта. Аутентифицируйтесь штатно через GitHub, не вставляйте токены в HTML.
Далее: репозиторий → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. GitHub покажет готовый HTTPS-адрес. Не используйте ссылку на HTML внутри github.com и не raw.githubusercontent.com.

## 4. Открытие из Telegram

Приложение уже поддерживает Telegram WebApp SDK: раскрытие окна, тему, безопасные отступы и кнопку «Назад». Проверено как статический сайт; реальный запуск в вашем боте требует вашего адреса сайта и настройки BotFather.

1. Сначала убедитесь, что HTTPS-сайт работает и права/доступ настроены.
2. В официальном @BotFather выберите своего бота (или создайте через `/newbot`).
3. Настройте Menu Button / Web App: укажите HTTPS-адрес опубликованного сайта и подпись «Открыть Wordly». Можно использовать `/setmenubutton`, если этот пункт доступен в текущем интерфейсе BotFather.
4. Откройте личный чат со своим ботом и нажмите кнопку меню.

Сервер обычного чат-бота, ежедневные уведомления, Telegram Login, облачная синхронизация и проверка initData в эту версию НЕ входят. Никаких токенов бота в HTML, GitHub или ссылках быть не должно.

## 5. Ограничения и офлайн

- Полная локальная папка содержит все исходные аудиозаписи. Один `index.html` без `assets` не является самостоятельным файлом.
- Сайт при первом открытии загружает оболочку/данные, картинки и аудио подгружаются по мере обращения. Не нужно сразу загружать все 300+ МБ.
- На HTTPS service worker кэширует оболочку и просмотренные изображения. Аудио не кэшируется массово; без интернета оно не гарантировано. Запуск Telegram WebView без сети тоже не гарантирован.
- Доступность системной озвучки и форматов видео зависит от устройства. Обычно MP4 H.264 + AAC совместим с Telegram.
- Часть русских переводов слов и примеров автоматическая, помечена и доступна для исправления. Грамматические ответы сверяются с ключом источника; дополнительные допустимые формулировки, которых нет в ключе, могут не распознаться.
- В этой поставке нет платных API, внешней генерации озвучки и фоновой отправки учебных данных. Telegram SDK загружается с telegram.org; медиа по вашим внешним ссылкам — с указанных вами серверов.
